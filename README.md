### 🚀&nbsp; Featured Projects

**[Smart Contact Manager 2.0](https://github.com/arpitsahu2203/SCM-Smart-Contact-Manager-)**

My strongest project — a full-stack contact manager with Spring Security 6 (OAuth2 login via Google & GitHub, BCrypt, RBAC) and MySQL persistence through Spring Data JPA. UI built with Thymeleaf + Tailwind + Flowbite, including dark mode. Fully Dockerized with a two-stage Maven build and Compose setup running the app alongside MySQL. Currently being decomposed into microservices as a capstone learning project.

`Spring Boot` `Spring Security` `OAuth2` `MySQL` `Docker` `Thymeleaf`

`Spring Boot` `JWT` `MySQL` `Spring Data JPA`
