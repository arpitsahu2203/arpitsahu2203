### 🧭&nbsp; About Me & Engineering Philosophy

- ☕ **Backend-First Mindset**: I specialize in **Java 21 and the Spring Boot ecosystem**, focusing on robust authentication mechanisms (OAuth2, JWT, RBAC), clean relational modeling (Hibernate/JPA), and production-grade REST APIs.
- 🏗️ **Distributed Systems Evolution**: Currently decomposing monolithic Spring applications into microservices leveraging **Spring Cloud Gateway, Eureka Discovery, Resilience4j Circuit Breakers, and Apache Kafka**.
- ✦ **AI-Native Engineering**: Building practical LLM pipelines with **Spring AI** (`ChatClient`, Ollama local models, and RAG architectures) to automate code analysis and spaced recall drills.
- 🎨 **Full-Stack Competency**: When the mission requires a UI, I build server-rendered, accessible frontends using **Thymeleaf, Tailwind CSS, and Flowbite**, as well as component-driven apps with **React**.
